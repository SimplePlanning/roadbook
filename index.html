GitHub 同步（备份 / 多台电脑）

路书库按「目录 = 文件夹，文件 = 路书」的结构存到仓库，例如 roadbooks/新疆自驾/第一天.json，每份路书一个独立文件，可直接在 GitHub 上查看。
上传=本地整库覆盖仓库（一个 commit，本地删掉的路书同步从仓库删除）； 拉取=用仓库覆盖本地（同步到这台电脑）。
到 github.com/settings/tokens 生成 Token（classic 勾 repo 权限；或 fine-grained 只给目标仓库 Contents 读写权限）。 Token 只存在这台电脑的浏览器 localStorage 里，每台电脑要各填一次。
注意：文件夹/路书名里的 / \ : * ? " < > | 会替换成 -； 提交到公开仓库（如本站的 gh-pages）后路书数据任何人可见，介意的话填一个你自己的私有仓库。
